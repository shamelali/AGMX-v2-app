# AGMX placeholders

These lightweight SVGs are intentionally local, brand-neutral placeholders. They prevent broken-image states while a reviewed free image is being selected.

## Available placeholders

- `hero.svg` — wide hero/OG placeholder.
- `workflow.svg` — AGM workflow or feature-card placeholder.
- `avatar.svg` — neutral member avatar placeholder.

Replace a placeholder with a licensed image only after adding its source, creator, license, and download date to `assets/IMAGE_SOURCES.md`. Keep meaningful `alt` text in the consuming HTML; use an empty `alt` attribute for purely decorative imagery.
