# AGMX v2.0 — Sprint 7 Spec: Registration + Presence + Quorum

Source: AGMX Master PRD v2.0 (GOV-01, §5 stage 7/8/9, §4 IA, Control requirements).

## Objective
Registration control, attendance session, presence event, quorum threshold and status; Readiness Centre compliance + technical rehearsal.

## Registration control
- RSVP, identity, attendance preparation (stage 7 gate: Participant ready)
- Notice acknowledgement and registration/RSVP (Hub requirement)
- Personal voting centre showing only eligible ballots (Hub requirement)

## Presence & Quorum
- Live counts: physical, online, total present, quorum threshold and quorum status (Control requirement)
- Quorum established gate before Convene (stage 9)
- Presence event, attendance session

## Readiness Centre (stage 8)
- Compliance + technical rehearsal
- Readiness score/gate

## Readiness gate
- Compliance + technical rehearsal → Readiness score/gate

## Acceptance criteria (this sprint)
- [ ] Participant can RSVP and register for an AGM.
- [ ] Live counts computed: physical, online, total present, quorum threshold, quorum status.
- [ ] Quorum evaluated before Convene; gate blocks proceeding without quorum.
- [ ] Readiness Centre runs compliance + technical rehearsal and computes readiness score/gate.
- [ ] Registration becomes immutable snapshot when election opens (§10).
